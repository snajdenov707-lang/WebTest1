# CRM · Заявки в Supabase

Заявки с формы заказа я записываю напрямую в PostgreSQL — таблица
`public.khrustiks_orders` в проекте Supabase `dark-deed`.

## Где смотреть заявки

1. Захожу на [supabase.com/dashboard](https://supabase.com/dashboard) под своим
   аккаунтом (проект **dark-deed**, id `nrwxylnanldzvkufxtsw`).
2. **Table Editor** → таблица **`khrustiks_orders`**.
3. Каждая новая заявка появляется там сразу же.
4. Столбец `status` веду вручную: `новая` → `в работе` → `отправлена` /
   `отменена` (кликом по ячейке).

## Что попадает в таблицу

| Колонка | Что это |
|---|---|
| `order_no` | номер заявки (K26-XXXX) |
| `product`, `color`, `size`, `price` | что заказали |
| `name`, `phone`, `email` | контакты покупателя |
| `city`, `zip`, `address` | адрес доставки |
| `delivery` | СДЭК / Почта России / Курьер |
| `comment` | комментарий покупателя |
| `status` | новая / в работе / отправлена / отменена |
| `source` | всегда `khrustiks.ru` |
| `created_at` | когда оформили |

## Безопасность (RLS)

- В `script.js` — `publishable`-ключ Supabase (тип по спецификации,
  предназначен для клиентского JS). Не путать с `service_role`.
- На таблице включён Row Level Security с единственной политикой:
  `for insert to anon with check (true)`.
- Практически: этим ключом можно **только вставлять** новые заявки.
  Читать, редактировать или удалять чужие записи — нельзя.
- Смотреть список заявок можно только из Dashboard, залогинившись
  под моим Supabase-аккаунтом.
