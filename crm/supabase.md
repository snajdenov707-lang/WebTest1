# CRM · Заявки в Supabase (основной способ — уже подключено)

Заявки с формы заказа пишутся напрямую в реальную базу данных
(PostgreSQL, проект Supabase). Настраивать ничего не нужно — уже работает.

## Где смотреть заявки

1. Зайди на **[supabase.com/dashboard](https://supabase.com/dashboard)**
   под своим аккаунтом (организация **Khrust**, проект **zendention**).
2. **Table Editor** → таблица **`orders`**.
3. Каждая новая заявка с сайта появляется там сразу же — имя, телефон,
   email, товар, цвет, размер, адрес, способ доставки, комментарий.
4. Столбец **`status`** — веди заявку вручную: `новая` → `в работе` →
   `отправлена` / `отменена`. Меняется прямо в таблице кликом по ячейке.

## Что попадает в таблицу `orders`

| Колонка | Что это |
|---|---|
| `order_no` | номер заявки (K26-XXXX) |
| `product`, `color`, `size`, `price` | что заказали |
| `name`, `phone`, `email` | контакты покупателя |
| `city`, `zip`, `address` | адрес доставки |
| `delivery` | СДЭК / Почта России / Курьер |
| `comment` | комментарий покупателя |
| `status` | новая / в работе / отправлена / отменена |
| `source` | всегда `khrustiks.ru` |
| `created_at` | когда оформили |

## Безопасность (уже настроено)

- В коде сайта (`script.js`) лежит **publishable-ключ** — это нормально,
  он публичный по своей природе (как ключ витрины). Им можно **только
  добавлять** новые заявки (RLS-политика `for insert to anon`).
- **Читать** чужие заявки этим ключом нельзя — таблица защищена Row Level
  Security. Смотреть список заявок можно только из Dashboard, залогинившись
  под своим Supabase-аккаунтом.

## Уведомления о новой заявке (по желанию)

Прямо сейчас заявки нужно проверять в Dashboard руками. Если хочешь,
чтобы при новой заявке сразу прилетало уведомление в Telegram/почту —
скажи, настрою через Supabase Database Webhook (пара минут).

## Экспорт / выгрузка

Table Editor → кнопка **Export** → CSV — выгрузишь все заявки одним файлом
(для Excel, 1С, чего угодно).

## Дублирование в Google Таблицу (опционально, необязательно)

Если хочешь **дополнительно** видеть заявки ещё и в Google Sheets (для
привычки или для доступа сотрудникам без Supabase-аккаунта) — см.
[`setup.md`](./setup.md). Это надстройка поверх Supabase, не замена —
Supabase работает независимо от того, подключишь ты Google Таблицу или нет.
