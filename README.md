# KHRUSTIKS · сайт

Тёмный премиум-лэндинг для бренда пуховиков **KHRUSTIKS**.
Три модели: **OBSIDIAN** (чёрный), **GLACIER** (белый), **ASHFALL** (серый).
Композиция вдохновлена референсами (COLLECTION ARTIC 01 / NEW COLLECTION / Stüssy Alpine).

## Файлы

```
index.html          — вся разметка (hero, story, коллекция, форма заказа, футер, модалка товара)
styles.css          — тёмная тема, типографика, адаптив
script.js           — каталог, модалка, размер/цвет, отправка формы
gemini-prompts.md   — промпты для фото (Gemini/Midjourney/Flux)
crm/
  apps-script.gs    — приёмник заявок в Google Sheets
  setup.md          — как подключить (5 минут)
```

## Запуск локально

Просто открой `index.html` двойным кликом — оно статическое.
Для чистой разработки лучше поднять простой сервер:

```bash
python -m http.server 5173
```

и открой `http://localhost:5173`.

## Подключить приём заявок в Google Таблицу

См. подробный шаг-за-шагом гайд: [`crm/setup.md`](./crm/setup.md).
Коротко: создай таблицу → Extensions → Apps Script → вставь [`crm/apps-script.gs`](./crm/apps-script.gs) →
Deploy как Web app (Anyone) → скопируй URL → вставь в `script.js` в переменную `CRM_ENDPOINT`.

Пока `CRM_ENDPOINT` пустой, форма имитирует отправку и пишет заявку в `console.log`
— удобно проверять UX без бэкенда.

## Подставить настоящие фото

1. Сгенерируй фото по промптам из [`gemini-prompts.md`](./gemini-prompts.md).
2. Положи их в папку `assets/` (структуру папки увидишь внизу файла с промптами).
3. Скажи «фото готовы» — заменю SVG-плейсхолдеры на реальные `<img>`.

## Дизайн-принципы (для консистентности)

- **Гамма:** только чёрный `#050505` / белый `#f4f2ee` / серый `#6d6a63`. Никаких цветных акцентов.
- **Типографика:**
  - Дисплей: `Archivo Black` — большие заголовки
  - Кондесед: `Space Grotesk` — навигация, кнопки, метки
  - Тело: `Inter` — параграфы
  - Моно: системный — служебные метки, «сканер»
- **Углы:** только `14px` радиус для карточек / кнопок. Пилюли (999px) для CTA.
- **Тени:** нет теней. Глубина только через границы `#1e1e1e` и шум.
- **Шум:** тонкая SVG-плёнка (см. `body::before`) поверх всего — держит «плёночность».
- **Иконки:** только моно-глифы (◆, ◯, ⌕, ◨) — никакого material/heroicons.
